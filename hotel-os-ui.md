Design the complete UI/UX for a premium hotel booking and hotel management platform called "Hotel OS".

PRODUCT CONCEPT

Hotel OS is a two-sided hospitality platform for Nigeria and eventually Africa.

There are two major experiences:

1. TRAVELER PLATFORM
A beautiful consumer-facing hotel discovery and booking marketplace where users can:
- Discover hotels by city, state, neighborhood, landmark, or location
- Search by check-in/check-out dates
- Specify guests and rooms
- Filter hotels
- Compare properties
- View hotel details, rooms, amenities, policies, reviews and photos
- Check real-time room availability
- Reserve rooms
- Pay online
- Receive booking confirmation
- Manage upcoming and past reservations
- Leave verified reviews after checkout

2. HOTEL OS DASHBOARD
A professional B2B SaaS dashboard for hotel owners, managers and staff where they can:
- Register their hotel
- Complete hotel verification
- Manage hotel profile
- Upload photos
- Manage amenities
- Create room types
- Manage physical rooms
- Manage prices
- Manage daily availability/inventory
- Manage reservations
- Manage guests
- View revenue and occupancy
- Manage hotel staff
- Manage subscriptions
- Manage payouts
- Eventually connect their existing PMS/hotel management system through API integrations

IMPORTANT PRODUCT DIFFERENTIATOR

Hotels do NOT have to replace their existing hotel management software.

Hotel OS should eventually allow hotels to connect their existing PMS and synchronize:
- Room types
- Availability
- Rates
- Reservations
- Cancellations

Therefore the UI should communicate that Hotel OS is both:
- A hotel management/distribution platform
- A marketplace that brings hotels new bookings

The product should feel like hospitality infrastructure rather than a simple hotel directory.

DESIGN DIRECTION

Create a premium, sophisticated, modern hospitality experience.

Do NOT make it look like:
- A generic AI-generated SaaS dashboard
- A basic Bootstrap admin panel
- A cheap hotel directory
- A direct copy of Booking.com
- A generic travel template

The visual language should feel like a combination of:
- Premium travel technology
- Modern luxury hospitality
- High-end SaaS
- Editorial travel magazines
- Modern African design sensibility

The interface should be elegant, confident, calm and highly usable.

Use:
- Strong typography
- Large immersive hotel photography
- Generous whitespace
- Refined cards
- Subtle borders
- Soft shadows
- Sophisticated spacing
- Beautiful image galleries
- Smooth micro-interactions
- Subtle motion
- Clear visual hierarchy

Avoid excessive:
- Glassmorphism
- Gradients
- Neon colors
- Excessive rounded cards
- Huge unnecessary headings
- Decorative UI with no functional purpose

Use rounded corners selectively and intentionally.

COLOR SYSTEM

Create a sophisticated hospitality color system.

Primary:
Deep charcoal / near-black

Background:
Warm off-white / ivory

Secondary:
Stone / warm gray

Accent:
A refined earthy green, deep emerald, or muted gold tone.

The overall experience should feel premium without looking expensive or flashy.

Support both:
- Light mode
- Dark mode

Light mode should be the default.

TYPOGRAPHY

Use a premium modern sans-serif for the main UI.

Use a tasteful editorial serif only where it adds character, such as:
- Large travel headlines
- Hotel storytelling sections
- Promotional sections

Typography should feel sophisticated but remain highly readable.

RESPONSIVE DESIGN

Design for:

- Mobile

The mobile experience is extremely important because many travelers in Nigeria will access the marketplace from mobile devices.

Build mobile-first interactions for:
- Search
- Hotel browsing

UX PRINCIPLES
==================================================

1. Minimize friction in booking.

2. Make hotel information easy to scan.

3. Photos should be visually important.

4. Prices must always be clear.

5. Availability must never be ambiguous.

6. Important actions should always be obvious.

7. Never hide important fees until the final step.

8. Make the hotel dashboard operationally efficient.

9. Avoid excessive visual decoration.

10. Prioritize real-world usability over flashy animations.

11. Use motion subtly:
- Page transitions
- Image transitions
- Hover effects
- Loading states
- Booking confirmation
- Calendar interactions

12. Design for unreliable/slow mobile networks:
- Efficient image loading
- Skeleton states
- Progressive loading
- Clear offline/error states
